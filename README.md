# lpcelite-astro (botones negros)

Copia del landing **Lokal Big Blanco** de [Calzados Elite](https://lp.calzadoselite.co/oferta/lokal-big-blanco), en [Astro](https://astro.build/), con botones y acentos en **negro** (`#000000`) en lugar del rojo original (`#ff1a47`).

## Desarrollo

```bash
npm install
npm run dev
```

Abre http://localhost:4321

## Producción

```bash
npm run build
npm run preview
```

## Nota

Las imágenes, videos y fuentes se cargan desde el sitio original (`lp.calzadoselite.co` y CDN de Shopify).
